# 地面刹车与速度回收

规则依据 `Docs/策划案v1.11.md` 的刹车条目及用户确认。高速按下 S 时启动刹车，A/D、W 和摄像机转动都不能改变人物朝向，相机仍可自由转动；保持 S 即使已刹停也不倒走，松开后重新按下才进入低速后退。低速 S、A+S、S+D 进入七方向行走，详见 Walking.md。空中、滑铲、滑铲起身姿态、划墙不执行刹车；墙面转角仍遵守墙切线约束。

`Assets/Settings/MovementParams.asset`：

| 字段 | 默认值 | 含义 |
| --- | --- | --- |
| BrakeDeceleration | 24 m/s² | 额外的恒定水平减速度，设为 0 不减速 |
| BrakeRecoveryWindow | 0.7 s | 刹车停止后允许跳跃返还的玩家时间 |
| BrakeStopSpeed | 0.05 m/s | 刹车后低于此速度归零，归零部分计入回收 |

地面普通摩擦先结算，再扣回收摩擦；高速开始的 S 刹车期间停止普通奔跑与冲刺增速。回收只累计刹车实际扣除的水平速度，不累计地面摩擦、滑铲减速、划墙摩擦、碰撞裁剪或动作强制清速。

刹车有效期间及结束后的窗口内，成功起跳返还暂存速度，方向采用起跳时的水平运动方向；完全停下时采用角色朝向。总速度受现有 MaxSpeed 限制。返还不改变竖直起跳速度，一次成功起跳后清空。跳跃预输入在按下时保存回收资格，沿用该次跳跃的预输入时长，实际起跳才返还。

进入空中、滑铲或划墙时停止回收摩擦并开始原有窗口倒计时，不因继续按住 S 而无限续期。松开 S 后可通过 W/A/D 调整朝向，再在窗口内跳跃。S 仍按住时起跳保持朝向，空中不再扣刹车速度。

动作段的 `Control.AllowBrake` 决定是否允许地面刹车，与移动、转向和跳跃权限独立。普通冲刺/能量加速在扣费前检查刹车输入。输入清空、死亡重生、Motor 停用、撞墙及明确清空水平动量的命令会清除回收缓存。S 不再提供 Backward 输入，不触发旧的 S + 右键折返；保留旧枚举编号，避免破坏历史示例资产。

F3 面板可查看刹车状态、可返还速度及窗口剩余时间。运动仍由 PlayerMotor 和 CharacterController 查询驱动，台阶/坡面跟随与脚部 IK 不参与速度回收。
