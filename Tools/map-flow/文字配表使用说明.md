# 地图文字配表

文字点预制体：`Assets/Prefabs/Flow/TextPoint.prefab`。

菜单：**超高速行者 → 流程与地图 → 配表窗口 → 差分 → 文字点与内容**。也可用 **文字点预制体** 菜单定位资产。

## 摆放和填写

1. 选择所属箱庭的一个差分，点击「新增文字点」。工具打开地图模板、放入文字点并分配 `TXT_` 编号。
2. 移动、旋转或缩放「地图文字点」根节点。内部 `Text3D` 的 TMP 组件设置文字区域宽高、换行和对齐方式。保存地图模板。
3. 回到差分，点击「刷新并同步文字点」。新点默认关闭，已有内容通过编号保留。
4. 勾选启用，展开对应文字点，填写内容、字号、颜色和播放参数；点击窗口下方「保存配表」。其他差分独立填写同一点的内容。
5. 「定位」可找到地图中的对应点。「预览当前差分文字」显示完成出现后的文字；「播放文字效果」直接播放一轮，便于检查排版和动画。「结束预览」恢复地图。预览不写入地图模板或差分内容，保存模板、进入播放、关闭模板、脚本重载时自动清理。

编号在移动和改名时保持不变。复制后点击「修复文字点缺失／重复编号」，保留第一个已有编号，其余点生成新编号。删除点位后，旧配置保留到显式点击「清理失效文字配置」。

## 差分参数

| 参数 | 含义 |
| --- | --- |
| 启用 | 本差分是否使用此点；受上级内容组是否启用的限制 |
| 文字内容 | 中文、多行及 TMP 富文本 |
| 字号、颜色 | 各差分独立设置；根节点缩放仍控制整体大小 |
| 触发方式 | 进入镜头：当前相机视锥与文字包围盒相交；进入当前房间：无需等待镜头。视锥检测不包含墙体遮挡检测 |
| 最大触发距离 | 相机到文字原点的距离，单位米；0 为不限制；两种触发方式都可受距离限制 |
| 显示方式 | 播放后消失，或出现后一直保持 |
| 停留时间 | 出现动画完成后的完整停留秒数；保持显示模式不使用此值 |
| 出现／消失效果 | 留空使用点位默认效果；通过文字动画效果资产替换 |
| 出现／消失速度 | 1 为原速，2 为两倍速度；实际动画时长为效果时长除以速度 |

默认使用 `Assets/Texture/Text3D` 导入的文字效果：2.5 秒从左向右显现、停留 2 秒、约 1 秒压平并溶解。

## 替换动画

默认效果资产在 `Assets/Settings/FlowText/Appearance.asset`、`Dissolve.asset`。通过 Project 右键 **Create → 超高速行者 → 流程 → 文字动画效果** 创建新效果，指定来源 AnimationClip，点击「重新读取动画曲线」并保存，再分配给差分或文字点默认效果。

支持来源动画根节点的 `material.*` 浮点曲线、材质槽 0 的切换，以及本地位置、缩放和 `localEulerAnglesRaw` 欧拉角曲线。不支持子节点轨道、四元数轨道或动画事件；读取时拒绝不支持的绑定，避免静默丢效果。修改来源动画后需要重新读取。文字宽度和溶解高度根据实际排版范围映射，不再依赖原动画的固定文字尺寸。

每个文字实例独立持有材质；材质使用当前中文字体图集，支持 TMP 的多图集子网格。原始出现与溶解 Shader 在导入目录使用独立的 `GameJam/Flow/` 名称。

## 运行规则

- 预加载仅绑定内容，保持隐藏，不开始计时。
- 房间成为当前房后才检测触发条件；默认每个点每次访问触发一次。
- 一次性文字离房后停止，返回同一次访问不重复播放；保持显示的文字返回时恢复完成状态。
- 死亡重建房间会重新绑定，允许教学提示再次播放。
- 文字动画与停留统一使用不受战斗时缓影响的时间，菜单暂停时停止。
- 房间卸载时释放实例材质。点位朝向固定在地图中，不自动追随镜头。
- 旧的「叙事文本」仍写入模板登记的 `TextMesh`，与新增文字点独立。

中文字体使用已有 `Assets/Art/UI/Fonts/NanoDotSong.ttf` 生成动态 SDF。工程补齐了现有 TMP 包的基础资源，没有增加包依赖。

## 验证

`Tools/map-flow/validate.ps1 -Stage TextInstall` 在隔离工程生成文字点资产；随后运行 `-Stage EditMode` 与 `-Stage PlayMode` 验证配置与房间生命周期。运行时和编辑器编译可用 `-Stage Compile`。
