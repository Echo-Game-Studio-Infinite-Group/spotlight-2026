# 菜单视觉参数

进入 `Assets/Scenes/MainMenu` 场景，在层级中选择同名对象，在检查器里改即可，记得别在运行状态下调参。

|效果|调整位置|当前值 / 含义|
|---|---|---|
|字体边缘红光呼吸|ButtonCRT.mat → Glow breath period / depth|3 秒一轮 / 0.75，亮度在 25%–100% 间平滑呼吸；depth 为 0 时关闭|
|按钮像素光扩散|ButtonCRT.mat → Pixel glow radius|24，纹理像素半径，可调 0–48|
|按钮发光强度 / 颜色|ButtonCRT.mat → Pixel glow strength / color|0.85 / RGB(0.78, 0.22, 0.26)；强度越高越亮|
|左右摆动|各按钮 CRTMenuButton → Tilt Degrees|±4°|
|摆动周期 / 相位|CRTMenuButton → Period / Phase|6 秒一轮；Phase 为弧度|
|悬停矩形展开|CRTMenuButton → Shutter Duration|0.3 秒|
|标题切入|CRTMenuPresentation → Flicker Duration / Entry Glitch|0.55 秒 / 0.9|
|标题平移|CRTMenuPresentation → Start / End Anchor X|0.25 → 0.5，屏幕宽度比例|
|标题平移时间 / 抽帧|Travel Duration / Intro Frame Rate|2.4 秒 / 8 帧每秒|
|标题淡出后亮度|Settled Opacity|0.55|
|标题高度 / 闪烁|Title Height / Flicker Frame Rate / Flicker Opacity|325 / 24 / 0.12|
|移动中 / 停稳故障强度|Travel Glitch / Idle Glitch|0.32 / 0.12|
|扫描线粗细|TitleCRT、ButtonCRT、ShutterCRT.mat → Scanline count|38 / 14 / 16，越小线越宽|
|扫描线明暗|同上 → Scanline strength|越大暗线越明显|
|海面 / 网格|PerspectiveTide.mat|Horizon 消失线，GridBrightness 网格亮度，DotBrightness 海浪亮度，Columns 点阵密度，FrameRate 抽帧，Speed 流速，WaveHeight 波高|
|按钮排布|MainMenuUI → Button Top / Button Spacing|-35 / 105；运行时由这里控制纵向排列|
|位置、尺寸、透视|对应对象 RectTransform|包括标题、按钮、设置面板；旋转会影响透视|
|悬停底色|Shutter 对象 RawImage → Color|暗红色 #64161E|
|字体 / 字号|BakeMenuText.py|纳米点宋；标题 132、副标题 42、按钮 52，修改后运行脚本重新生成文字贴图|

材质都在 `Assets/Art/UI/CRT/`。字体是烘焙贴图，RawImage 的尺寸只改变显示缩放。动画周期和帧率必须大于 0（废话）。
