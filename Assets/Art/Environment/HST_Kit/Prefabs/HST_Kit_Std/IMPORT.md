# HST_Kit_Std —— 环境标准件库（v17）

Blender 参数化直出的统一度量衡标准件，按物品类型分目录，地编拖 prefab 即可拼装。
直出/迭代方法（三步：hst 加行 → Blender 导出 → Unity 烘焙）与**硬表面设计语言六条**见外层
`docs/技术/墙板预制件直出指南.md`；交付规范权威见 `docs/技术/地编Kit拆分与交付.md`。
**尺寸列口径 = Unity 实测 宽×高×深（x/y/z，单位 m）**；棚拍自检图：外层 `_render_kitstd_blender/`（Blender 设计语言）
与 `_render_kit_std/`（Unity 交付目检）。

## 坐标约定（2026-10-14 定，直出必守）

一律 **Blender 自然 Z-up：宽沿 x、高沿 z、厚沿 ±y**。导出器的 Z-up→Y-up 转换由 FBX 导入节点
TRS 承载，烘焙器逐件复制该 TRS；若像早前那样把高度写在 y 上（在 Blender 里其实是躺平的），
交付到 Unity 就会躺倒。墙类 v=0,0,1 / 厚沿 y。

## v16 改动（用户 2026-10-14 二批裁定）

- **发光嵌缝条 / 灯带条不再独立成件**：嵌缝本来就是地板的一部分、灯带本来就是天花板的一部分。
  改为 `floor_tile` 的 `seam=` 与 `ceil_plate` 的 `lit=` 开关；拼铺后自动连成发光网格 / 通长光带
- **挑台（platform）出库**
- **楼梯重做（v17）**：用户裁定"太窄、要实心的那种" → 改成**实心梯段**（阶梯剖面整宽挤出的
  一整块实体，可当承重体/掩体），净宽 3.0 / 4.0 m，踏步口径不再自拟、改用《建筑与人尺度规格》
  已定值 **rise 0.1667 / run 0.28**（原 0.28/0.45 是自拟且过陡）
- **集装箱按真实 20 尺 ISO 重做**（6.058×2.438×2.591）：八角件 + 四角柱 + 上下边梁 + 四面梯形
  波纹钢壁 + 门端双开门（锁杆/铰链/把手）+ 顶面横向波纹；**旧地图那六只异色箱合成一体垛**
  （`P_集装箱垛`，2×2 落位、两列各叠一层，涂装照旧场：橙 / 深碳 / 深蓝）
- **可破坏件整体出库**：先换成塑料周转箱/能量罐，用户再裁定"造型千篇一律、尺寸超过半人高、
  精度不够" —— 全部删掉，改由**独立资产线**交付：`scripts/props/`（铁门同款工具库
  `lib_hardsurface`/`door_kit`、真 chamfer 三级倒角、四件不同造型、≤半人高），
  产出 `exports/packages/jem-assets_props-destruct_v1_*.zip`。本库不再含可破坏件

## 设计语言（Functional / Industrial Chamfer Sci-Fi Hard Surface）

1. **切角与弧倒角**：所有实体走 `plate_poly`（135° 折角）或 fillet 轮廓挤出，emit 再上 Bevel 三段
   135° 弧 —— 全库无 90° 锐角轮廓
2. **功能件可读**：每个细节都读得懂用途（角件/边梁=箱体框架、波纹壁=钢皮、锁杆=可封、
   堆叠唇口=可码放、提手凹槽=可搬、底脚=离地、斜梁=承重、防滑前缘=防滑、锚板=固定）
3. **可破坏读法**：本条库不含可破坏件（已出库）。可破坏道具在独立资产线 `scripts/props`，
   走"量产杂物/耗材"语汇（工程箱 / 能量罐 / 军械盒），**不做刻意设计的木箱**
4. **工业分层**：浅色结构主体（顶点色逐件色差）+ 深色硬件（dark2/metal/dark）+ 单一哑光橙功能标记
   + 至多一处青发光指示点
5. **琥珀口径**：琥珀（haz）只留给坠落危险边缘，功能标记一律用哑光橙（orange）
6. **模块尺寸**：1.2m 主网格；楼梯 rise 0.28 / run 0.45（码常数）；六边形墙 4.8×3.6 一节；
   集装箱 20ft ISO 外廓

## 材质

- 平色件：`材质/M_M_*.mat`（URP/Lit），地编可做材质变体换色
- **自发光（v16 补链）**：manifest 一直带 `emit/emit_str`，但 `materials.tsv` 早先漏了这两列，
  导致 M_cyan/M_lamp/M_band/M_hazard/M_blue_dot 在 Unity 侧全成不发光平色 —— 这就是"发光条不亮、
  六边形墙在 Unity 里没光感"的根因之一。现已补进 TSV，烘焙器读第 7/8 列写入 `_EmissionColor`
- 顶点色件（贴板墙/板场地台/塑料箱/楼梯踏板/六边形墙）：导出按顶点色 8 级量化切子网格，
  Unity 侧成 `M_M_panel_q4..q7` 多档灰 —— "不同深浅"靠几何+多档材质，不吃贴图
- 贴图件（P_走廊地板 → `材质/M_T_Floor.mat`）：克隆自
  `Assets/Art/Materials/HST_Prags/M_ARCH_FloorM`（FloorPlate_White 贴图组），**依赖
  HST_Prags 贴图资产，随走廊套件一体交付**；世界三平面 UV 已烘进网格。
  导出侧按材质名跳过发光件，所以嵌缝条不会被换成贴图
- **带贴图件的摆位纪律**：prefab 摆位取 4.8 的整数倍，UV 相位才与世界网格对齐

## Unity 侧工位（交付目检，必跑）

- `bash tools/unity-batch.sh HST.KitBaker.BakeStdCatalogAndStills`
  → `Assets/Scenes/SC_HST_Kit_Std_Catalog.unity`（真实比例目录，地编可浏览取件）
  + `_render_kit_std/` 三张等视觉大小全景（`ALL_全景` 22 件 / `既有` 11 件 / `新做` 11 件，
  各带 `<图名>.labels.tsv`）+ 每类目一张（出图时只留本类目可见，避免邻类目大件窜镜）
  + 重点件特写若干（真实比例掠射光；名单见 `HstKitBaker.HeroShots`）
- 叠标注：`python scripts/scene/sheet_labels.py <图>.png` → `<图>_标注.png`（真实相机投影 + 件名 + 真实尺寸）
