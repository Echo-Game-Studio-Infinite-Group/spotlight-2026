# 流程和地图生成定稿

目前这版流程统合了之前的方案和设计，做了一定的简化，力图能在工期内把流程做完



1\.混乱度

概念:指示当前地图的混乱程度，显示于屏幕的右上角

混乱度的数值决定两件事情:

1\.当前箱庭采用哪个差分

2\.当前单元箱庭群是否是循环的单元箱庭群



常见情况下，混乱度范围为0\-100

特殊情况下，混乱度可以变为负数或者999



在最基本的情况下，我们可以认为混乱度指示了这一盘游戏的完成程度，即把混乱度作为一盘的完成度



基本的情况下，需要让玩家认识到，混乱度的增加会有益于过关（这个观念是可以被解构掉的）







2\.箱庭和地图生成



箱庭指一个在不使用门（此处的门不包含速度墙）的前提下处处联通的房间，往往包含战斗区域和跑酷要素的两者之一（或两者兼有）





地图池:箱庭的集合，中盒子和大盒子的不同差分被认为是集合中不同的元素



现有的地图池:

1\.不会引起混乱度变化的普通地图

2\.会引起混乱度变化的普通地图

3\.剧情房（视工期而定，目前先并入地图池1）

4\.特殊行为房间（或许看工期）

5\.999房间（看工期）

6负数房间（看工期）





差分:地图在不同混乱度下会有某种差分，差分的形式包括:场地内物件的不同，场地内敌人配置不同，场地内文字叙事不同，场地内灯光可能不同

一张地图的差分数应当在1（仅一种模式）\-6之间

地图差分变化阈值可以是个性化的，但无特殊情况最好契合下面的循环流程



地图生成:若不处于循环模式，进入当前房间时，从地图池中按权重roll出当前房间的后继，拼接在当前地图后（无缝加载），当前房间（被进入后）在地图池中的权重降为原先的1/4



存在一个全局的队列，进入房间后将当前房间编号入队，房间内复活点重设后pop至只剩当前房间（这个是为了避免一些存档问题，若每个房间都放存放点就不用做）



循环模式:

当混乱度为在0\-30 80\-100时，若不处于循环模式，则进入循环模式

此时，从地图池1roll出3或6个房间，池2roll出1个房间，构成循环



3 死亡与复活点

死亡后，回到记录点/复活点







复活点应当被设置在刚进入房间的位置



在当前房间的第一个记录点完成后，进入房间的门关闭，卸载当前房间的话前驱



掉下裂隙损失血量，回到记录点

复活方式图省事可以用存档系统，读档后修改混乱度，如果场景内敌人的状态重置比较完善的话可以重置当前房间状态，回到记录点



回到记录点时，当前房间的差分根据当前混乱度而定



一个房间内可以有多个记录点



记录点不需要额外操作，站到附近可以触发

记录点处应当有某种提示，例如一个小雕像

同一房间内的多个记录点应当有优先级关系，流程上靠后的记录点优先级应当更高（当设计复杂的房间内动线时，可以让某个记录点再次覆盖）







4\.混乱度提升与降低



为简化系统，提升混乱度的方式定为击碎房间内的一个灯（稳定装置），可以提升10/15点混乱度



死亡后降低10点混乱度，回到记录点，在一般的情况下，死亡不会让混乱度低于0

根据工期，本节内容可能被裁撤
